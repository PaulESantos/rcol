# rcolapi: Client for the 'Catalogue of Life' and 'ChecklistBank'

Access the Catalogue of Life (COL) through the 'ChecklistBank'
application programming interface (API) <https://api.checklistbank.org>.
Match scientific names against public datasets or COL releases and
retrieve accepted names, synonyms, classifications and geographic
distributions. Discover datasets and releases, navigate taxonomic trees
and parse names and controlled values. Return tabular results with input
provenance and per-row diagnostics for batch matching failures.
